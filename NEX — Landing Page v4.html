Frequently Asked Questions

What is NEX?
NEX is a Luau executor with a Monaco editor, built in terminal, workspace file management, and a live settings panel, all in one clean dark UI.
What games does NEX support?
NEX works with any game that supports Luau injection. The editor highlights standard Luau and Roblox builtins out of the box.
Is my data stored anywhere?
No. Scripts and settings are saved to your local machine only. NEX does not send anything to external servers.
How do I get support?
Join the NEX Discord for help, updates, and script sharing from the community.
What is NEX built on?
NEX runs on Tauri with a Monaco editor frontend. The UI is a single file HTML build, fast, lightweight, and self contained.
